# Structured JSON Audit Log Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Append every query, auth, and mutation event as one JSON line to an append-only `audit.jsonl` next to the KB database.

**Architecture:** New `itkb/audit.py` module (`audit_log_path` + best-effort `log_event`), a new `audit_enabled: bool = True` config field, and six small hooks in `app.py`, `cli.py`, and `tools.py`. Event schema: `{"event": <name>, "ts": <utc iso>, <fields>}`.

**Tech Stack:** Python 3.11, FastAPI + TestClient, pytest + pytest-mock, stdlib json/datetime.

**Reference spec:** `docs/superpowers/specs/2026-07-24-audit-log-design.md`

## Global Constraints

- `log_event` is best-effort: swallows all exceptions, never breaks the caller.
- Never log secrets: `auth.login` logs `success` only (no key); `command` logs command/exit_code only (no stdout/stderr).
- Query event logged ONCE per query (not per streamed token).
- `audit_enabled=False` → `log_event` is a no-op (no file created).
- No changes to retrieval/agent logic.
- Health gates at the end: `flake8 itkb tests`, `mypy itkb` (via `/opt/homebrew/opt/python@3.11/bin/python3.11 -m mypy itkb`), `python3 -m pytest -q` (104 baseline + ~10 new ≈ 114 passed).
- Run pytest as `python3 -m pytest` from the repo root. Tests must not touch real `~/.itkb` (use the `cfg_mod.CONFIG_DIR/CONFIG_FILE` monkeypatch pattern).

```python
# itkb/audit.py
from __future__ import annotations
import json
from datetime import datetime, timezone
from pathlib import Path


def audit_log_path(db_path: str) -> Path:
    return Path(db_path).parent / "audit.jsonl"


def log_event(db_path: str, event: str, **fields) -> None:
    """Append one JSON line to audit.jsonl. Best-effort: never raises."""
    try:
        from itkb.config import load_config

        if not load_config().audit_enabled:
            return
        record = {"event": event, "ts": datetime.now(timezone.utc).isoformat()}
        record.update(fields)
        with open(audit_log_path(db_path), "a") as f:
            f.write(json.dumps(record) + "\n")
    except Exception:
        pass
```
